# Multiplayer Quiz Game

A Python socket-based multiplayer quiz game for up to 4 players.

## Project Files
- server.py
- client.py
- game_logic.py
- data_manager.py

## How to Run
- Clone or download the project to your local computer.
- Open the project folder in **VS Code desktop**.
- Make sure Python is installed on the computer.
- Open a terminal in the project folder.
- For connection to another PC make sure you are running on the same local network with firewall disabled.

### Start the Quiz Game
- Run: py server.py
- Run: py client.py on a different terminal or another pc.
- Enter the server PC's IPv4 Address
